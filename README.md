# Matlas — Informative Technical Research

*Matlas: An Operational Map of Human Mars* · JB Bullock · First Public Web Edition 1.0 · October 2026 (conditional on publication within October).

This curated research branch contains the **three author-approved informative companion papers**, their individually licensed Markdown sources and publication PDFs. Technical material is **not** a new MGRID normative issue or a certified BAR, MRR-1, MB3/Triplet implementation. The illustrated book and its 97 selected images are separately copyrighted and will be readable at https://iamjbcom.github.io/matlas/ after separate release approval.

See `PUBLICATIONS.md`, `RIGHTS.md`, and `STATUS.md`. Each paper requires its own separate Zenodo publication authorization and eventual DOI.
